# v61e: v61c排名掉出Top15 + 涨跌幅确认启动信号 实验结论

## 实验日期
2026-09-03

## 核心假设
v61c选低换手+小市值的Top15。如果一只股票之前在Top15，现在掉出去了：
- 排名下降 = 换手率升高/市值变大 = 被市场关注
- 这种"关注度变化"可能是启动信号
- 加涨跌幅判断确认：近期有涨幅的才买

## 选股逻辑
1. 计算v61c因子得分（换手率+小市值）
2. 保存历史排名（跨bar）
3. 找出"5天前在Top15，现在掉出去"的股票
4. 加涨跌幅条件：5日涨幅>1%确认启动
5. 排除已持仓，按涨跌幅排序选前N只

## 结论

### ❌ 假设不成立
"排名掉出Top15"作为启动信号的思路**不成立**。

### 原因分析
1. **排名掉出 = 资金在撤**：换手率升高/市值变大，说明资金在流出，不是流入
2. **涨幅确认太弱**：即使加了涨幅条件（>1%），选到的股票质量一般
3. **快进快出能降风险**：3天持有期能把回撤从-23%降到-16%，但Sharpe仍远低于v61c

### 关键教训
1. **排名下降≠启动信号**：v61b中"排名下降收益更好"的发现，可能是其他因素（如板块轮动），不是排名本身
2. **启动信号需要更强的确认**：仅靠涨幅不够，可能需要成交量、资金流向等更直接的指标
3. **v61c的alpha来源稳定**：低换手+小市值的组合，在不同市场环境下都有正alpha

## 建议
放弃此方向，v61c的alpha来源（低换手+小市值）更可靠。如需寻找启动信号，建议：
1. 研究资金流向因子（北向资金、融资余额等）
2. 研究板块轮动效应（行业动量）
3. 研究事件驱动因子（业绩预告、解禁等）
