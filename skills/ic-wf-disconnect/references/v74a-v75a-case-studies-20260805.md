# IC-WF脱节案例集（2026-08-05）

## 案例1：v74a 行业动量增强 — IC强但WF惨败

**IC分析**：行业动量→个股收益 IC=0.1767, IR=0.9575, 胜率83.2%
**WF结果**：Sharpe -0.768, 1/15正fold（7%）, 平均收益-10.88%

**脱节原因**：
1. **选股域不一致**：IC用全市场1800只计算，但行业动量因子让56%无映射股票的ind_mom=0.0被排到最后，实际选股域只有~800只
2. **行业轮动换手太高**：周度Top5行业重叠仅28%，每周几乎全换，交易成本吞噬alpha
3. **5日短周期不适合行业趋势**：行业趋势持续性>2周，5天切换纯摩擦
4. **行业动量有前视偏差嫌疑**：用当前行业分类映射到历史数据，IC可能虚高

**教训**：
- IC的选股域必须与WF实际选股域一致
- 行业轮动策略在A股牛市中效果差，应聚焦主线板块
- IC高不代表策略可执行——换手率是被IC忽略的关键维度

## 案例2：v75a 科技趋势增强 — IC弱但WF大胜

**IC分析**：突破+放量+流动性组合 IC=-0.0188, IR=-0.1008（微弱负信号）
**WF结果**：Sharpe 1.642, 12/15正fold（80%）, 平均收益+39.59%

**脱节原因**：
1. **IC是线性度量，WF是非线性的**：IC衡量截面排序与未来收益的单调关系，但v75a的收益来自少数几个牛市fold（+110%, +97%, +76%），这些极端收益在IC中被平均掉了
2. **集中持仓放大收益**：3只持仓+30%止盈，让趋势充分发展。IC不考虑仓位集中度
3. **IC跨regime平均**：2023-2025熊市IC为负，2026牛市IC为正，平均后接近零。但WF中牛市fold贡献了绝大部分alpha
4. **板块锁定降低了分散性**：IC在全市场计算，v75a只在4个板块内选股，信号更集中

**教训**：
- IC弱≠策略弱，特别是集中持仓+高止盈的策略
- 分regime分析IC比整体IC更有价值
- 牛市弹性策略的alpha集中在少数fold，IC会低估其价值

## 案例3：v75b MA50过滤 — 慢过滤杀死动量

**v75a（无过滤）**：Sharpe 1.642, 80%正fold, +39.59%
**v75b（MA50过滤）**：Sharpe 0.146, 53%正fold, +4.54%

**教训**：
1. **慢过滤器伤momentum策略**：MA50太慢——牛市启动时来不及上车（错过前20-30%涨幅），离场也太慢（回撤已发生才卖出）
2. **回撤降低但收益降更多**：回撤24%→17%，但收益40%→5%，不划算
3. **动量策略需要快速入场**：与价值策略不同，动量策略的alpha在于"早发现早参与"，慢过滤直接摧毁了这个优势
4. **结论：v75a不做过滤更好**，高收益覆盖高回撤

**通用规则**：
- 动量/趋势策略：用快速信号（价格突破、量价配合），不用慢速MA
- 价值/低波动策略：可以用慢速MA过滤，因为它们本身就不依赖快速入场

## 案例4：v75c regime门控失效 — 数据源缺失导致门控形同虚设

**问题**：v75c的regime检测使用`get_index_kline("sh000001")`，但`index_kline`表中只有ETF（sh512880等），没有上证指数。函数返回空列表，默认`return True`，导致门控完全失效——v75c的WF结果与v75a完全相同。

**诊断方法**：
```python
# 检查index_kline表内容
import sqlite3
conn = sqlite3.connect('data/quant_stocks.db')
codes = [r[0] for r in conn.execute('SELECT DISTINCT code FROM index_kline').fetchall()]
print(codes)  # 只有ETF，没有sh000001
```

**修复**：用科技板块等权指数（从daily_kline计算）替代上证指数：
```python
# ❌ BAD — 返回空，默认允许交易
kl = get_index_kline("sh000001")  # → []
return True  # 门控失效

# ✅ GOOD — 从daily_kline计算板块指数
tech_codes = [c for c in load_industry_codes() if c in close_panel.columns]
sector = close_panel[tech_codes].mean(axis=1)
above_ma = sector[date] > sector[date-50:date].mean()
```

**教训**：
- 使用外部数据源前必须验证数据是否存在
- `return True`作为默认值会让门控形同虚设——应该`return False`（保守）或抛异常
- 自建板块指数比依赖外部指数更可靠
