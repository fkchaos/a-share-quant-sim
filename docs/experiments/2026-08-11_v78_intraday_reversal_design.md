## 1. 背景与动机

### 1.1 问题
v77隔夜收益率已证伪（IC=-0.0099）。需要继续探索新的alpha来源。

### 1.2 假说
日内反转因子（intraday reversal）：
- `intraday_return = close[t] / open[t] - 1`（取负值）
- A股T+1制度下，日内涨幅过大 → 次日获利了结 → 反转效应
- 与隔夜收益互补：隔夜反映集合竞价情绪，日内反映连续竞价博弈
- 学术文献：A股短期反转是被广泛验证的异象

### 1.3 与现有因子相关性
- 隔夜收益：已证伪
- 流动性(illiq)：低相关（illiq衡量价格冲击，日内反转衡量日内涨跌）
- 换手率：中等相关（高换手可能伴随大波动）
- 需要验证：与v75j的illiq因子IC相关性

## 2. 因子定义

### 2.1 核心因子
```python
intraday_return = close[t] / open[t] - 1
# 取负值：日内涨幅大 → 负向信号（预期反转下跌）
factor = -intraday_return
```

### 2.2 变体（备选）
```python
# 变体1：5日平均日内反转
intraday_5d = (close / open - 1).rolling(5).mean()
factor_v2 = -intraday_5d

# 变体2：波动率调整的日内反转
intraday_vol = (close / open - 1).rolling(20).std()
factor_v3 = -(close / open - 1) / intraday_vol
```

### 2.3 验证标准
| 指标 | 阈值 | 判定 |
|------|------|------|
| \|IC Mean\| > 0.03 且 \|IR\| > 0.3 | 有效，进入WF |
| \|IC Mean\| < 0.01 或 \|IR\| < 0.1 | 证伪 |
| 0.01-0.03 | 微弱信号，不值得WF |
