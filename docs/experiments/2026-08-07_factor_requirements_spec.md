# 策略生产线输入项需求规格说明书

> 版本：v1.0 | 日期：2026-08-07 | 作者：小赫一世

---

## 1. 背景与目标

### 1.1 我们是谁
我们是一个**A股量化策略生产线**，专注于：
- 科技趋势策略（当前基准：v75j，WF Sharpe 1.960）
- 低换手小票策略（当前基准：v61b，WF Sharpe 2.152）

### 1.2 我们要什么
我们需要**标准化的策略输入项**，用于持续开发新策略。输入项分为三层：
1. **选股因子**：用于在截面上对股票排序，回答"买什么"
2. **择时信号**：用于判断市场状态，回答"什么时候买/卖多少"
3. **风控参数**：用于控制组合风险，回答"亏多少止损/赚多少止盈"

### 1.3 合作目标
我们希望与因子研究团队合作，获取**经过验证的、可直接集成的**策略输入项。

## 2. 需求分类

### 2.1 选股因子（Stock Selection Factors）

**定义**：用于在截面上对股票排序的因子，回答"买什么"。

**我们感兴趣的类别**：

| 类别 | 示例因子 | 数据来源 | 优先级 |
|------|----------|----------|--------|
| 技术面 | 流动性、波动率、换手率、量价背离 | K线数据 | ⭐⭐⭐ |
| 基本面 | PE/PB/ROE/营收增速/净利润增速 | 财报数据 | ⭐⭐ |
| 资金面 | 北向资金、主力资金、融资融券 | 资金流向 | ⭐⭐ |
| 情绪面 | 涨停数、跌停数、市场宽度 | 盘面统计 | ⭐ |
| 另类数据 | 龙虎榜、连板晋级率、封单结构 | 交易所数据 | ⭐ |

**验证标准**：

| 指标 | 阈值 | 判定 |
|------|------|------|
| \|IC Mean\| > 0.03 且 \|IR\| > 0.3 | 有效，进入WF验证 |
| \|IC Mean\| < 0.01 或 \|IR\| < 0.1 | 证伪，不进入WF |
| 0.01-0.03 | 微弱信号，不值得投入WF时间 |

**特别要求**：
- 必须提供**分regime的IC分析**（强势/弱势市场分别计算）
- 必须提供**IC衰减分析**（近12个月IC趋势）
- 必须说明**经济逻辑**（为什么这个因子有效）

### 2.2 择时信号（Timing Signals）

**定义**：用于判断市场状态的信号，回答"什么时候买/卖多少"。

**我们感兴趣的类别**：

| 类别 | 示例信号 | 数据来源 | 优先级 |
|------|----------|----------|--------|
| 市场宽度 | 涨跌家数比、MA20以上家数占比 | 盘面统计 | ⭐⭐⭐ |
| 趋势 | 大盘均线位置、MACD信号 | 指数数据 | ⭐⭐ |
| 情绪 | 涨停溢价率、连板高度 | 盘面统计 | ⭐⭐ |
| 波动率 | VIX类似指标、ATR | 指数数据 | ⭐ |

**验证标准**：

| 指标 | 阈值 | 判定 |
|------|------|------|
| 阈值过滤回测Sharpe > 1.5 | 有效，进入WF验证 |
| 阈值过滤回测Sharpe < 1.0 | 证伪，不进入WF |
| 1.0-1.5 | 边缘，需要额外验证 |

**特别要求**：
- 必须提供**最优阈值**和**阈值敏感性分析**
- 必须提供**胜率**和**盈亏比**
- 必须说明**触发逻辑**（什么条件下触发/不触发）

### 2.3 风控参数（Risk Control Parameters）

**定义**：用于控制组合风险的参数，回答"亏多少止损/赚多少止盈"。

**我们感兴趣的参数**：

| 参数类别 | 参数名 | 范围 | 优先级 |
|----------|--------|------|--------|
| 止损 | STOP_LOSS | -5% ~ -15% | ⭐⭐⭐ |
| 止盈 | TAKE_PROFIT | 20% ~ 50% | ⭐⭐⭐ |
| 持仓时长 | HOLD_DAYS_MAX | 5 ~ 30天 | ⭐⭐ |
| 仓位控制 | MAX_POSITION | 20% ~ 50% | ⭐⭐ |
| 持仓数量 | MAX_HOLDINGS | 3 ~ 10只 | ⭐ |

**验证标准**：

| 指标 | 阈值 | 判定 |
|------|------|------|
| 风控参数回测Sharpe > 1.0 | 有效，进入WF验证 |
| 风控参数回测Sharpe < 0.8 | 证伪，不进入WF |
| 0.8-1.0 | 边缘，需要额外验证 |

**特别要求**：
- 必须提供**参数组合**（不要单参数，要组合优化结果）
- 必须提供**最大回撤**和**收益回撤比**
- 必须说明**适用条件**（什么市场环境适用/不适用）

## 3. 格式要求

### 3.1 选股因子格式

```json
{
    "name": "factor_name",
    "type": "stock",
    "category": "technical|fundamental|alternative",
    "direction": "positive|negative",
    "data_source": "data_source_name",
    "calc_logic": "human-readable calculation logic",
    "ic_mean": 0.05,
    "ir": 0.4,
    "regime_dependency": "all|strong_only|weak_only|none",
    "decay_status": "stable|decaying|expired",
    "expiry_date": null,
    "source": "external",
    "description": "一句话描述"
}
```

```json

    },
    "backtest_sharpe": 1.8,
    "win_rate": 0.75,
    "regime_dependency": "all",
    "decay_status": "stable",
    "source": "external",
    "description": "一句话描述"
}
```

## 4. 交付物要求

### 4.1 必须交付

| 交付物 | 格式 | 说明 |
|--------|------|------|
| 因子代码 | Python函数 | 符合我们的calc_factors签名规范 |
| 因子说明 | Markdown文档 | 包含经济逻辑、计算逻辑、数据来源 |
| IC/IR分析结果 | CSV/JSON | 全局IC + 分regime IC + IC衰减 |
| 回测结果 | CSV/JSON | Sharpe、收益、回撤、胜率 |
| 数据源说明 | Markdown文档 | 数据来源、更新频率、历史长度 |

### 4.2 可选交付

| 交付物 | 格式 | 说明 |
|--------|------|------|
| 因子相关性分析 | CSV/JSON | 与现有因子的相关性 |
| 压力测试结果 | CSV/JSON | 不同市场环境下的表现 |
| 参数敏感性分析 | CSV/JSON | 参数变化对结果的影响 |

## 5. 合作流程

### 5.1 对接流程

```
Step 1: 需求沟通
  └─ 我们提供本需求文档
  └─ 对方确认理解需求

Step 2: 因子开发
  └─ 对方按格式要求开发因子
  └─ 我们提供数据访问权限（如需要）

Step 3: 交付验收
  └─ 对方交付因子代码+文档+分析结果
  └─ 我们按验证标准验收

Step 4: 集成测试
  └─ 我们将因子集成到策略研发流程
  └─ 跑WF验证
  └─ 反馈结果

Step 5: 正式合作
  └─ WF验证通过后，进入正式合作
  └─ 持续提供新因子
```

### 5.2 时间要求

| 阶段 | 时间 | 说明 |
|------|------|------|
| 需求沟通 | 1-2天 | 确认需求理解一致 |
| 因子开发 | 1-2周 | 根据复杂度 |
| 交付验收 | 3-5天 | 我们验收+反馈 |
| 集成测试 | 1-2周 | WF验证 |

### 5.3 质量要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 代码规范 | PEP8 | Python代码规范 |
| 文档完整 | 必须 | 说明文档+数据源文档 |
| 可追溯 | 必须 | 数据来源+计算逻辑 |
| 可复现 | 必须 | 给定数据能复现结果 |
