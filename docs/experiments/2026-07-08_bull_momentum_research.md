## 一、调研结论摘要

### 1. 牛市行情特征（2025-2026 A股）

当前A股处于牛市**主升期→扩散期**过渡阶段：
- **启动期**（2019.01-2020.03）：金融搭台，券商+银行先涨
- **主升期**（2020.04-2021.02）：科技成长+消费，半导体+202%，新能源+189%
- **扩散期**（2021.03-2021.12）：周期补涨，煤炭+87%
- **2025年特征**：AI+半导体领涨（科技板块+45%），小盘风格活跃

**牛市轮动规律**：板块轮动速度快，热点持续3-7天，每个阶段领涨板块不同。

### 2. 可行策略方向分析

| 方向 | 代表策略 | 日频可行性 | 我们的历史教训 | 结论 |
|------|---------|-----------|---------------|------|
| **概念热度+动量选股** | BigQuant概念热度策略 | ✅ 可行 | v66/v68已验证动量有效 | ⭐ **推荐** |
| 打板/追涨停 | 连板策略 | ❌ 分钟频依赖 | v49/v65已证伪（日频） | ❌ 不适合 |
| 行业轮动 | 美林时钟+行业ETF | ⚠️ 需行业分类 | v46行业动量负增量 | ⚠️ 谨慎 |

| 龙头股追踪 | 连板+概念匹配 | ⚠️ 需L2数据 | v56/v63未验证 | ⚠️ 待验证 |
| 量价突破 | 新高+放量 | ✅ 可行 | v58a证伪（假突破多） | ❌ 不推荐 |

### 3. 2026年打板生态变化（重要警告）

根据中国基金报（2026-04-12）调研：
- **打板策略正在衰落**：量化打板盈亏比恶化，多家机构放弃
- **监管收紧**：独立交易单元被禁、价格笼子机制、异常撤单监控
- **因子衰减极快**：封板率、溢价等因子"这周好使，下周失效"
- **趋势**：从T+0日内博弈 → 2-5日事件驱动短线
- **结论**：纯打板不适合我们（日频+无L2数据），但**概念热度+趋势跟随**仍有价值

### 4. 最可行方向：概念热度驱动的动量策略

**核心逻辑**（借鉴BigQuant概念热度策略，适配日频）：

```
牛市赚钱 = 买对板块 + 买对个股 + 及时止盈

Step 1: 识别最热概念板块（3日+15日涨幅双维度）
Step 2: 从热板块中选强势个股（动量+量能+市值过滤）
Step 3: 市场情绪择时（涨停数>阈值才开仓）
Step 4: 快速止盈止损（持3-5天，赚8-15%就走）
```

**与现有策略的区别**：
- v61b：低换手小票（冷门策略）→ 牛市踏空
- v68：小票动量+情绪择时（中性偏小票）
- **新策略**：**纯追热点+追强势**，不买冷门票，专买最热板块的龙头

## 二、策略设计：v71 概念热度追涨

### 2.1 策略定位

- **策略类型**：牛市追高追热点
- **适用市场**：牛市/强震荡市（熊市自动停止）
- **持仓周期**：1-5天（短线）
- **预期特征**：高收益高波动，依赖牛市环境
- **与v61b/v68互补**：v61b买冷门小票，v68中性偏小票，v71买最热板块龙头

### 2.2 数据需求

**现有数据足够**：
- daily_kline表：open/high/low/close/volume/amount
- stock_pool_zz1800：成分股列表
- industry_map表：行业分类（申万一级）

**需要新增的数据**：
- **概念板块数据**：概念板块成分股映射、概念板块日行情
  - 数据源：东方财富概念板块（akshare `stock_board_concept_name_em` + `stock_board_concept_cons_em`）
  - 存储：`data/concept_boards.db`（新表）
  - 更新频率：每日收盘后

### 2.3 因子设计

#### 因子1：概念热度得分（ConceptHeat）

```python
# 概念热度 = 3日涨幅排名分 + 15日涨幅排名分
concept_heat = w_short * rank_pct(concept_ret_3d) + w_long * rank_pct(concept_ret_15d)

# 要求短期+中期都在前20%（双维度验证）
# 候选概念 = concept_heat > 0.8 且 rank_3d > 0.8 且 rank_15d > 0.8
```

**为什么用3日+15日双维度**：
- 纯3日：噪音太大，追到一日游题材
- 纯15日：太慢，热点已切换
- 双维度：确保是**持续性热点**，不是昙花一现

#### 因子2：个股强势度（StockStrength）

```python
# 个股强势度 = 动量分 + 量能分 + 封板分
stock_strength = (
    w_mom * rank_pct(mom_5d) +           # 5日动量
    w_vol * rank_pct(vol_ratio_5d) +      # 量比（5日均量/20日均量）
    w_limit * rank_pct(limit_up_3d)       # 3日内涨停次数（情绪加分）
)
```

**关键约束**：
- EXCLUDE_LIMIT_UP=True（排除当天涨停，买不进）
- 排除ST、科创板（68开头）、北交所
- 市值≥20亿（避免微盘股）
- 成交额≥5000万（流动性保障）

#### 因子3：市场情绪择时（MarketSentiment）

```python
# 情绪指标：全市场涨停数的5日均值
market_sentiment = limit_up_count.rolling(5).mean()

# 择时规则：
# - sentiment > THRESHOLD → 允许开仓
# - sentiment < THRESHOLD → 停止开仓（但不强制平仓）
```

**与v68的区别**：
- v68用的是v67的情绪择时（连续两天涨停数）
- v71用更直接的指标：全市场涨停数
- 逻辑：牛市时涨停数多 → 追热点有效；熊市涨停数少 → 不追

### 2.4 选股流程

```
每日选股（上午信号）：
1. 查询所有概念板块的3日/15日涨幅
2. 计算概念热度得分，选Top3最热概念
3. 取这3个概念的成分股交集（已在zz1800中）
4. 计算个股强势度得分
5. 过滤：排除涨停/ST/科创/市值<20亿/成交额<5000万
6. 按强势度排序，取Top N
7. 情绪择时：如果market_sentiment < 阈值，不选新股（但仍持有已有）
```

## 四、风险提示

1. **概念数据获取是最大不确定性**：akshare接口稳定性、数据覆盖率
2. **牛市依赖性强**：该策略在熊市会大幅亏损（情绪择时可缓解但不能消除）
3. **追热点本质是动量策略**：A股动量在短周期有效，但存在反转风险
4. **与v68可能有持仓重叠**：都需要动量因子，需监控
5. **概念板块分类可能变化**：东方财富会调整概念分类，需定期验证
