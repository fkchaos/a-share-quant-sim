# v77 隔夜收益率因子 设计文档

> 日期：2026-08-11 | 状态：设计完成，待IC验证

---

## 1. 背景与动机

### 1.1 问题
v75j（流动性单因子+广度过滤）WF Sharpe 1.960，已接近天花板。需要寻找与现有因子低相关的新alpha来源。

### 1.2 假说
A股散户占比高（约60%交易量），隔夜期间散户情绪过度反应导致：
- 隔夜高开（overnight_return > 0）→ 散户追涨 → 次日反转下跌
- 隔夜低开（overnight_return < 0）→ 散户恐慌抛售 → 次日反弹上涨

**核心逻辑：隔夜收益率是散户情绪的代理变量，与机构行为低相关。**

### 1.3 学术支持
- 短期反转因子在A股有效已被广泛验证（IC均值约0.03-0.05）
- 隔夜收益率是日内收益的分解部分，与日内收益互补
- 中信证券研报将"行为数据"列为A股蓝海Alpha来源

---

## 2. 因子定义

### 2.1 计算公式
```
overnight_return[t] = open[t] / close[t-1] - 1
```

### 2.2 因子方向
- **负向因子**：隔夜收益率越高 → 次日越可能下跌 → 排序时取负值
- 排序：`factor = -overnight_return`（高排序 = 隔夜低开 = 买入候选）

### 2.3 滚动窗口
- 单日值：`overnight_return[t]`
- 5日均值：`MA5(overnight_return)` — 平滑噪声
- 20日均值：`MA20(overnight_return)` — 中期趋势

### 2.4 与现有因子相关性预期
| 因子 | 预期相关性 | 理由 |
|------|-----------|------|
| illiq（流动性） | 低（<0.2） | 流动性衡量交易难度，隔夜收益衡量情绪 |
| turnover（换手率） | 低（<0.2） | 换手率衡量交易活跃度，隔夜收益衡量方向 |
| breakout（突破） | 中（0.3-0.4） | 突破因子隐含价格动量，与隔夜收益部分重叠 |

## 3. 方案对比

| 方案 | 描述 | 优势 | 劣势 |
|------|------|------|------|
| A: 单因子v77 | 隔夜收益率单因子选股 | 简单，IC验证直观 | 单因子可能不够强 |
| B: 隔夜+日内组合v77+v78 | 两个因子各0.5权重 | 互补（隔夜vs日内） | 需要两个因子都有效 |
| C: 隔夜+illiq组合 | 隔夜0.4 + illiq0.6 | 与v75j兼容 | 可能不如v75j单因子 |

**选择方案A**：先验证单因子有效性，再考虑组合。

## 4. 验证条件

### 4.1 IC验证标准
| 指标 | 阈值 | 判定 |
|------|------|------|
| \|IC Mean\| > 0.03 且 \|IR\| > 0.3 | 有效，进入WF |
| \|IC Mean\| < 0.01 或 \|IR\| < 0.1 | 证伪，不进入WF |
| 0.01-0.03 | 微弱信号，不值得投入WF时间 |

### 4.2 WF验证条件
- train=252, test=126, step_days=63
- start='2021-01-01', end='2026-05-31'
- pool=zz1800
- 标杆策略: v39g（Sharpe 1.297, 16 folds）

### 4.3 分Regime IC分析
- 强势市场（breadth > 0.5）：IC可能较弱（趋势主导）
- 弱势市场（breadth < 0.3）：IC可能较强（反转效应更强）

---

## 5. 空仓逻辑（什么条件下不交易）

**与v75j共用广度过滤**：
- breadth_ma=20, breadth_high=0.50, breadth_low=0.30
- 当市场宽度 < breadth_low 时空仓（弱势不交易）
- 当市场宽度 > breadth_high 时满仓（强势积极交易）

---

## 6. 风险提示

1. 隔夜收益率是T+0数据，需要T+1才能计算，信号有1天延迟
2. 涨停/跌停可能导致open=close，隔夜收益率=0，信号失效
3. 新股上市初期隔夜波动大，可能污染因子
4. 因子衰减：A股技术因子半衰期约18个月，需定期重测
