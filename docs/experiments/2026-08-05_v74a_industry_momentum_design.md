# v74a 设计文档 — 行业动量增强层

> 2026-08-05 | 状态：设计中

---

## 1. 背景与问题

v61b 策略（低换手小票）在 2026-08-04 大盘暴涨 +5.64%（创业板）时仅微亏，暴露了核心缺陷：

- **选股完全忽略行业维度**：低换手+小市值因子选出的传统行业股票，在资金极度聚焦 AI/科技的市场中无人问津
- **牛市资金高度分化**：主线板块（AI算力、CPO、光刻机）涨幅 6%+，非主线（银行、地产、纺织）横盘或下跌
- **结果**：v61b 跑输大盘 -5.97%，v68 跑输大盘 -6.47%

## 2. 方案设计

### 2.1 核心思路

在 v61b 的低换手+小市值打分基础上，叠加 **行业动量因子**，让策略倾向选择"热门行业中的冷门股"。

### 2.2 行业动量因子定义

**行业动量得分** = 加权合成过去 N 日行业指数收益率：

```
industry_momentum(industry, date) = 
    w1 * ret_5d(industry) + 
    w2 * ret_10d(industry) + 
    w3 * ret_20d(industry)
```

其中：
- `ret_Nd(industry)` = 该行业所有股票过去 N 日平均收益率
- 权重：w1=0.4, w2=0.3, w3=0.3（参考鹏扬基金研究，短期动量权重更高）
- 行业分类：申万一级行业（使用现有 industry_map 表，31 个行业）

### 2.3 股票打分

```
v74a_score = alpha * low_turnover_rank + 
             beta * small_cap_rank + 
             gamma * industry_momentum_rank
```

- `low_turnover_rank`：v61b 原始低换手排名分（0-1）
- `small_cap_rank`：v61b 原始小市值排名分（0-1）
- `industry_momentum_rank`：该股所属行业的动量排名分（0-1）

**参数选择**：
- alpha=0.35, beta=0.35, gamma=0.30（行业动量占 30%，不喧宾夺主）
- 或 alpha=0.25, beta=0.25, gamma=0.50（行业动量主导，激进版）

### 2.4 行业动量衰减机制

当一个行业连续 N 天领涨时，动量得分逐步衰减，防止追高：

```
if industry领涨天数 > DECAY_THRESHOLD:
    industry_momentum_rank *= DECAY_FACTOR
```

- DECAY_THRESHOLD = 10 天
- DECAY_FACTOR = 0.7

### 2.5 调仓逻辑

保持 v61b 的 overlay 模式不变：
- 每只股票独立计算 entry_date
- REBALANCE_DAYS = 5
- 只在打分阶段叠加行业动量

## 3. IC 验证计划

### 3.1 行业动量因子 IC

- 计算 31 个申万一级行业的 ret_5d, ret_10d, ret_20d, 以及加权合成得分
- 用 IC 均值、IR、IC 胜率验证行业动量对 **行业下期收益** 的预测能力
- 预期：|IC Mean| > 0.03, |IR| > 0.3 → 有效因子

### 3.2 合成打分 IC

- 在 zz1800 股票池内，计算每日 v74a_score 对下期收益的 IC
- 与 v61b 原始 IC 对比

## 4. WF 回测计划

- 条件：train=252, test=126, step=63, start=2021-01-01, end=2026-06-24
- 标杆：v39g (Sharpe 1.297)、v61b (Sharpe 2.152)
- 对比两个参数组合：
  - v74a-conservative: alpha=0.35, beta=0.35, gamma=0.30
  - v74a-aggressive: alpha=0.25, beta=0.25, gamma=0.50

## 5. 风险点

1. **行业动量可能不稳定**：短期动量在震荡市中衰减快，可能导致频繁换行业
2. **行业分类滞后**：申万行业分类调整频率低，新兴产业可能被错分
3. **幸存者偏差**：industry_map 仅覆盖 795 只股票（当前快照），历史回测需注意
4. **与 v61b 低换手逻辑可能冲突**：热门行业往往换手率高，会与低换手因子产生矛盾

## 6. 实验编号

- v74a-conservative: alpha=0.35, beta=0.35, gamma=0.30
- v74a-aggressive: alpha=0.25, beta=0.25, gamma=0.50

### 7.7 诊断与修复（2026-08-05）

**WF首次失败**（2/15正fold，Sharpe -0.855）：
- **根因1：行业映射覆盖率仅44%**（795/1800），56%股票无行业映射
- **根因2：无映射股票ind_mom=0.0**（初始化值），被rank排到最后，永远不被选中
- **根因3：两个分类体系混用**（申万39个 + 证监会37个），同行业被拆分

**修复措施**：
1. 用BaoStock补齐1005只缺失股票的行业映射（C39→电子, I65→计算机...）
2. 补充27个未映射行业（I64互联网→计算机, C29橡胶→基础化工...）
3. 对仍为证监会分类的16只股票做最终映射
4. 最终：1800只全覆盖，31个行业
5. 对无行业映射股票设NaN而非0.0，rank时用中位数填充

**第二次WF**：修复后重跑中...

### 7.9 最终结论：❌ 证伪

**IC强但WF弱的原因**：
1. **行业动量换手太高** — 周度Top5行业重叠仅28%，每周几乎全换，交易成本吞噬alpha
2. **5日短周期不适合行业轮动** — 行业趋势持续性通常>2周，5天内来回切换纯交摩擦
3. **牛市资金极度集中** — 2024-2026牛市主线（AI/科技）持续性强，但策略在非主线行业间轮动反而踩坑
4. **行业动量有前视偏差嫌疑** — 用当前行业分类映射到历史数据，IC可能虚高

**教训**：
- IC分析的选股域（全市场1800只）和实际WF的选股域可能不一致
- 行业轮动策略在A股牛市中效果差，应聚焦主线板块
