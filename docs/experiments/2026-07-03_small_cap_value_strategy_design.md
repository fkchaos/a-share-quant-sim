# 方案B：小微盘价值策略设计文档

## 背景
汇安基金调研显示，2026年小盘风格占优。聚宽策略天梯中，小微盘策略年化收益可达60%+。

## 方案概述
开发小微盘价值策略，聚焦中证1000-2000区间的中小盘价值股，通过PB-ROE框架筛选优质公司。

## 选股逻辑

### 1. 市值区间
- 主仓：中证1000-1500（中等市值）
- 次仓：中证1500-2000（小微盘）

### 2. 价值因子
| 因子 | 说明 | 筛选条件 |
|------|------|----------|
| PB | 市净率 | < 3.0 |
| ROE | 收益率 | > 15% |
| ROA | 资产回报率 | > 10% |
| 毛利率 | 盈利能力 | > 30% |
| 净利率 | 盈利质量 | > 10% |

### 3. 财务筛查
- 剔除：财务报表异常、净资产为负、上市不足1年
- 关注：近期盈利增长、营收稳健

### 4. 技术面信号
- 价格处于5-20日均线之间
- 成交量放大1.5倍以上
- 无明显放跌

## 风控

- 单只仓位上限：15%
- 停损：8%
- 赢利方面：持有30天后止盈20%
