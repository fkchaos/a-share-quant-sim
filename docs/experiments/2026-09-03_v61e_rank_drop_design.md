# v61e: v61c排名掉出Top15 + 涨跌幅确认启动信号

## 核心假设

v61c选低换手+小市值的Top15。如果一只股票之前在Top15，现在掉出去了：

- 排名下降 = 换手率升高/市值变大 = 被市场关注
- 这种"关注度变化"可能是启动信号
- 加涨跌幅判断确认：近期有涨幅的才买

## 选股逻辑

1. 计算v61c因子得分（换手率+小市值）
2. 找出排名掉出Top15的股票（今天不在Top15，但之前在）
3. 加涨跌幅过滤：近期有涨幅的确认启动
4. 选符合条件的股票

## 参数

- `RANK_TODAY_N`: 今日Top N范围，默认15
- `MIN_RANK_CHANGE`: 最小排名下降幅度，默认5
- `MIN_PCT_3D`: 3日最小涨幅，默认1%
- `MIN_PCT_5D`: 5日最小涨幅，默认2%

## 与v61c对比

| 维度 | v61c | v61e |
|------|------|------|
| 选股逻辑 | 选Top15 | 选排名掉出Top15 + 涨幅确认 |
| 假设 | 低换手小票有alpha | 排名下滑=关注度变化=启动信号 |
| 风控 | 相同 | 相同 |
