# 策略研发全流程框架

> 2026-08-07 | 基于v75系列复盘的改进

---

## 1. 背景与动机

### 1.1 v75系列暴露的问题

| 问题 | 现象 | 根因 |
|------|------|------|
| IC分析regime盲区 | 全局IC=-0.04，但强势regime下IC=+0.012 | 全局IC掩盖regime-dependent有效性 |
| 弱信号优化陷阱 | v75h全量+29%但WF-11% | 对|IC|<0.03因子做权重优化=拟合噪声 |
| 择时/选股混淆 | 广度过滤是择时层，但流程中没有区分 | 验证方法不同（截面IC vs 阈值过滤） |
| 流程不标准化 | 每次新策略从头设计 | 缺乏统一框架和工具化 |

### 1.2 目标

建立一套**可重复、可验证、可监控**的策略研发流程，覆盖：
- 因子研究（选股因子 + 择时因子统一入口）
- 策略构建（分层设计）
- 验证（三道关卡）
- 集成上线
- 持续监控

## 2. 核心原则

### 2.1 统一入口，分层处理

**所有alpha来源（选股因子、择时因子）走同一个研究流程，但根据因子类型选择不同的验证方法。**

```
┌─────────────────────────────────────────────────┐
│           统一因子研究流程（阶段1）                │
│  ┌─────────────┐     ┌─────────────┐             │
│  │  选股因子    │     │  择时因子    │             │
│  │ (cross-      │     │ (time-      │             │
│  │  sectional)  │     │  series)    │             │
│  └──────┬──────┘     └──────┬──────┘             │
│         │                    │                    │
│         ▼                    ▼                    │
│  ┌─────────────┐     ┌─────────────┐             │
│  │ 截面IC/IR   │     │ 阈值过滤    │             │
│  │ 分析        │     │ 回测        │             │
│  └──────┬──────┘     └──────┬──────┘             │
│         │                    │                    │
│         ▼                    ▼                    │
│  ┌─────────────────────────────────┐             │
│  │  统一门槛：有效性判定            │             │
│  └─────────────────────────────────┘             │
└─────────────────────────────────────────────────┘
```

### 2.2 先筛选后优化

**因子有效性筛选（IC门槛）必须在权重优化之前完成。**

```
Step 1: 因子有效性筛选（|IC|>0.03, |IR|>0.3）
         ↓ 通过
Step 2: 策略构建（等权组合，不优化）
         ↓
Step 3: WF验证（通过后才考虑优化）
         ↓ 通过
Step 4: 权重优化（可选，且必须WF验证）
```

### 2.3 分层设计

**策略必须明确区分"选股层"和"择时层"，不能混淆。**

```
┌─────────────────────────────────────┐
│  Layer 1: 择时层（仓位管理）        │
│  输入：择时因子 → 输出：仓位比例     │
├─────────────────────────────────────┤
│  Layer 2: 选股层（标的筛选）        │
│  输入：选股因子 → 输出：股票排序     │
└─────────────────────────────────────┘
```

#### 0.2 选股因子标准

**定义**：用于在截面上对股票排序的因子，回答"买什么"。

**格式要求**：
```python
{
    "name": "liquidity",           # 因子名称（唯一标识）
    "type": "stock",               # 固定值：stock
    "category": "technical",       # 分类：technical/fundamental/alternative
    "direction": "negative",       # 方向：positive（越大越好）/ negative（越小越好）
    "data_source": "tencent_kline", # 数据源
    "calc_logic": "amt / volume_10d_avg",  # 计算逻辑描述
    "ic_mean": -0.054,            # IC均值（验证后填写）
    "ir": -0.31,                  # 信息比率（验证后填写）
    "regime_dependency": "weak_only",  # regime依赖性：all/strong_only/weak_only/none
    "decay_status": "stable",     # 衰减状态：stable/decaying/expired
    "expiry_date": null,          # 过期日期（null=永久有效）
    "source": "internal",         # 来源：internal（内部生成）/ external（外部获取）
    "description": "流动性因子，低换手率股票表现更好"
}
```

**元数据要求**：
| 字段 | 必填 | 说明 |
|------|------|------|
| name | ✅ | 唯一标识，小写+下划线 |
| type | ✅ | 固定值：stock |
| category | ✅ | technical/fundamental/alternative |
| direction | ✅ | positive/negative |
| data_source | ✅ | 数据来源（需可追溯） |
| calc_logic | ✅ | 计算逻辑描述（人类可读） |
| ic_mean | ✅ | IC均值（验证后填写） |
| ir | ✅ | 信息比率（验证后填写） |
| regime_dependency | ✅ | regime依赖性 |
| decay_status | ✅ | 衰减状态 |
| expiry_date | ❌ | 过期日期（null=永久有效） |
| source | ✅ | internal/external |
| description | ✅ | 一句话描述 |

**验证方法**：截面IC/IR分析（阶段1执行）

**示例**：
| 因子 | IC均值 | IR | 判定 |
|------|--------|-----|------|
| 流动性 | -0.054 | -0.31 | ✅ 通过 |
| 突破 | -0.014 | -0.08 | ❌ 不通过 |
| 放量 | -0.011 | -0.06 | ❌ 不通过 |

### 阶段1：因子研究（统一入口）

**目标**：从候选池中筛选出有效因子（|IC|>0.03, |IR|>0.3）

#### Step 1: 候选池构建

| 因子类型 | 候选来源 | 示例 |
|----------|---------|------|
| **选股因子** | 技术指标、基本面、另类数据 | 动量、换手率、PE、龙虎榜 |
| **择时因子** | 市场情绪、广度、波动率 | 广度%、涨停数、VIX |

**工具**：`scripts/tools/factor_candidate_pool.py`
- 自动从数据源提取候选因子
- 输出：因子定义表（名称、类型、计算逻辑、数据源）

#### Step 2: 经济逻辑验证

**每个因子必须回答"为什么有效"，不能纯数据驱动。**

| 问题 | 要求 |
|------|------|
| 预测逻辑 | 这个因子预测什么？为什么能预测？ |
| 市场机制 | 哪些市场行为导致这个因子有效？ |
| 边界条件 | 什么情况下会失效？ |
| 预期IC | 基于逻辑，预期IC是多少？ |

**不通过则淘汰，不进入下一步。**

#### Step 3: 因子有效性筛选

**根据因子类型选择验证方法：**

| 因子类型 | 验证方法 | 门槛 |
|----------|---------|------|
| **选股因子** | 截面IC/IR分析 | \|IC Mean\| > 0.03 且 \|IR\| > 0.3 |
| **择时因子** | 阈值过滤回测 | 阈值组合Sharpe > 1.0 |

**工具**：`scripts/tools/factor_ic_analysis.py`

```python
# 选股因子：截面IC
factor_ic_analysis(factor_df, factor_type='stock')

# 择时因子：阈值过滤回测
factor_ic_analysis(factor_df, factor_type='timing', thresholds=[...])
```

**输出**：ICResult对象，包含：
- IC均值、IR、胜率
- 分regime IC（强势/弱势/震荡）
- IC衰减曲线
- 有效性判定（通过/不通过）

**不通过则淘汰，不进入下一步。**

#### Step 4: 分regime分析

**在不同市场环境下分析因子表现：**

| Regime | 定义 | 分析内容 |
|--------|------|---------|
| 强势 | 广度>50% 或 指数>MA50 | 因子IC是否显著为正？ |
| 弱势 | 广度<30% 或 指数<MA50 | 因子IC是否显著为负？ |
| 震荡 | 其他 | 因子IC是否接近0？ |

**关键发现**：
- 如果因子只在特定regime有效 → 需要配合择时层
- 如果因子在所有regime都有效 → 独立有效
- 如果因子在所有regime都无效 → 淘汰

#### Step 5: IC衰减分析

**因子有效性是否随时间衰减？**

- 计算滚动IC（6个月窗口）
- 识别衰减趋势
- 估算半衰期

**门槛**：当前IC > 0.02（否则不值得用）

#### Step 6: 因子相关性分析

**保留|corr|<0.5的因子，避免多重共线性。**

**工具**：`scripts/tools/factor_correlation.py`

### 阶段2：策略构建

**基于筛选后的有效因子，构建策略。**

#### 2.1 因子组合

**默认等权组合，避免过度优化。**

```python
# 示例：两个有效因子等权
W_FACTOR_A = 0.5
W_FACTOR_B = 0.5
```

**只有在WF验证通过后，才考虑权重优化。**

#### 2.2 策略结构设计

**必须明确分层：**

```
Layer 1: 择时层（可选）
  └─ 输入：择时因子（如广度）
  └─ 输出：仓位比例（0-1）

Layer 2: 选股层
  └─ 输入：选股因子（如动量+流动性）
  └─ 输出：股票排序
```

**必须回答"什么条件下不交易"（空仓逻辑）。**

#### 2.3 参数初始化

**不优化，先用默认值：**
- 择时阈值：基于分regime分析确定
- 选股权重：等权
- 风控参数：行业标准（止损-8%、止盈30%、持仓15天）

### 阶段3：验证（三道关卡）

**必须按顺序通过，不能跳步。**

#### 3.1 全量回测（初筛）

**目的**：快速排除明显无效的策略

| 指标 | 门槛 | 说明 |
|------|------|------|
| Sharpe | > 0.5 | 基本有效性 |
| 最大回撤 | < 50% | 风控底线 |
| 正收益年份 | > 60% | 稳定性 |

**工具**：`run_wf(full=True)`（快20倍）

**不通过则返回阶段2调整，不进入WF。**

#### 3.2 Walk-Forward验证（核心）

**目的**：验证样本外泛化能力

| 参数 | 标准值 | 说明 |
|------|--------|------|
| train | 252天 | 1年训练期 |
| test | 126天 | 半年测试期 |
| step_days | 63天 | 季度滚动 |
| start | 2021-01-01 | 起始日期 |
| end | 2026-05-31 | 结束日期 |
| pool | zz1800 | 股票池 |

**门槛**：

| 指标 | 通过 | 警告 | 不通过 |
|------|------|------|--------|
| WF Sharpe | > 1.5 | 1.0-1.5 | < 1.0 |
| 正fold比例 | > 70% | 60-70% | < 60% |
| 收益稳定性 | 最差fold > -20% | -20%~-30% | < -30% |

**不通过则返回阶段2调整。**

#### 3.3 压力测试（可选）

**在极端市场环境下测试策略：**
- 2024年熊市（2024-01-01 ~ 2024-09-30）
- 2025年牛市（2025-01-01 ~ 2025-12-31）
- 2026年震荡（2026-01-01 ~ 2026-05-31）

**目的**：识别策略的regime依赖性

## 9. v75j实验结果（2026-08-07）

### 9.1 实验设计

**假设**：突破和放量是弱信号（IC<0.03），去掉后策略表现更好

**方法**：
- v75j = v75f去掉突破和放量因子
- 只保留流动性单因子（IC=-0.054，有效）
- 广度过滤保持不变

### 9.2 WF结果

| 指标 | v75f | v75j | 变化 |
|------|------|------|------|
| WF Sharpe | 1.806 | **1.960** | **+8.6%** ✅ |
| 平均收益 | 44.2% | **57.90%** | **+31.0%** ✅ |
| 平均回撤 | 18.4% | **17.24%** | **-6.3%** ✅ |
| 正fold | 93% | 80% | -13% ⚠️ |

### 9.3 结论

**✅ 假设成立**：去掉弱因子后策略表现更好

**关键发现**：
1. 突破和放量确实是弱信号（IC<0.03），去掉后策略更纯净
2. Sharpe提升8.6%，收益提升31%，回撤降低6%
3. 正fold降低13%（稳定性略降，但整体更优）

**教训验证**：
- ✅ "弱信号优化=拟合噪声"——去掉弱因子后表现更好
- ✅ "IC筛选是必要的"——IC<0.03的因子确实不应该保留
- ✅ "先IC筛选再构建策略"——新流程有效
