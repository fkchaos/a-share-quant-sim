## 结论

### 1. 估值因子整体微弱
- PB最接近通过阈值（|IC|=0.048, |IR|=0.29），但不够（需|IR|>0.3）
- PE更弱（|IC|=0.032, |IR|=0.20）

### 2. 方向解读
- **PB负IC** = 低PB预测高收益（价值效应），符合传统金融学
- **PE负IC** = 低PE预测高收益（价值效应），但信号弱
- **但A股科技板块**：高估值=高成长=高收益，价值效应被成长效应抵消

### 3. 单日截面IC不可靠
- 单日截面IC：PE=+0.24, PB=+0.22（非常高！）
- 多日时序平均IC：PE=-0.032, PB=-0.048（大幅衰减）
- **教训**：单日IC受极端值影响大，必须做多日时序平均

### 4. 因子组合能否改善IC/IR？

**理论上可以，但实际效果取决于因子间相关性：**

| 组合方式 | 预期效果 | 实际限制 |
|----------|----------|----------|
| **等权平均** | IC提升√N倍（N=因子数） | 前提：因子间低相关 |
| **IC加权** | 按历史IC分配权重 | 需要足够长的历史IC序列 |
| **PCA降维** | 去除冗余维度 | 可能损失解释性 |
| **机器学习** | 非线性组合 | 过拟合风险高 |

**当前因子相关性分析：**
- PE vs PB：高度相关（r>0.8），组合后IR提升有限
- 估值 vs 流动性：低相关（r<0.3），组合有潜力
- 事件 vs 技术：几乎无相关，但事件因子本身太弱

**结论：**
1. **PE+PB组合**：效果有限（高度相关）
2. **估值+流动性组合**：有潜力（低相关），但流动性因子已是v75j核心，叠加估值可能引入噪声
3. **事件因子**：IC太弱（<0.02），组合也无法挽救

### 5. 下一步建议
1. **完成PE/PB数据补全**（断点续传进行中）
2. **测试估值+流动性组合IC**（验证低相关因子组合效果）
3. **转向外部数据源**（龙虎榜、北向资金、融资融券等微观结构数据）
4. **考虑因子非线性处理**（分位数、截断、regime切换）

## 踩坑记录
1. akshare代码格式：返回int代码（2726），需str.zfill(6)补零
2. CSV存储不保留dtype：int存CSV再读回来还是int
3. DB兼容性：新表用CREATE TABLE IF NOT EXISTS + INSERT OR REPLACE
4. 批量接口速度：腾讯API比akshare快60-1000倍
5. 断点续传：长任务必须做checkpoint，gateway可能随时重启
