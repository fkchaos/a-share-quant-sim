# 讯投QMT使用小技巧: trade client not found 无法找到trade client

> 来源: https://invest.wtsolutions.cn/posts/qmt-trade-client-not-found/

在QMT使用的过程中，我们有时会收到报错，trade client not found 无法找到trade client，我之前遇到这个情况的时候，qmt连续24小时运行，然后第二天的时候，会出现这类报错，导致qmt无法正常运行。

我目前没有找到非常有效的解决方案，我能做的就是， 在手机上收到报错提醒的时候，立刻人为干预，重新启动qmt，就可以正常运行了。我另外还做了尝试就是联系券商，让他们给我发一个最新版本的qmt安装程序，使用最新的版本，目前看这个问题在安装新版本之后解决了，但我也不确定是不是因为这个原因，但我会建议大家做一下这些尝试，看看有没有解决。
